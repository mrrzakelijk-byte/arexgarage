# Arex Garage

Alle bestanden staan direct in deze map. Upload ze samen naar de hoofdmap van je GitHub-repository. Open `index.html` met Live Server om de site lokaal te bekijken. Op GitHub Pages is `index.html` ook de eerste pagina.

De toegangscode in `index.html` is alleen een eenvoudig scherm voor bezoekers. Op een openbare statische site zijn de code, pagina's en afbeeldingen via de bronbestanden of directe URL's alsnog te bekijken. Gebruik dit dus niet voor echt vertrouwelijke inhoud. Houd de bestaande online Site alleen voor de eigenaar toegankelijk zolang de AI-beelden niet publiek mogen zijn.
