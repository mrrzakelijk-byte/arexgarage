# Arex Garage

Alle bestanden staan direct in deze map. Upload ze samen naar de hoofdmap van je GitHub-repository. Open `index.html` met Live Server om de site lokaal te bekijken. Op GitHub Pages is `index.html` ook de eerste pagina.

De website is zonder inloggen toegankelijk. `index.html` toont direct de homepage; `home.html` blijft beschikbaar voor bestaande links.
